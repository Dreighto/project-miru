## What to build

A card detail page for Monkey D. Luffy (OP01-001) styled to match the PM Storefront's dark theme.

The page has three sections:

### 1. Fixed top bar (sticky header, same pattern as the real app's detail drawer header)
- Back button (← arrow icon, 44×44px tap target, gold color on active)
- Card code + name on the right of the back button
- Close button (×, top-right)

### 2. Scrollable content area
- Card image placeholder (aspect-ratio 5/7, rounded corners, dark surface bg,
  centered monospace card code like the real app does when no image is available)
- Rarity + set line (small gold monospace badge for rarity, muted text for set)
- Tab switcher with three tabs: "Details" | "Variants" | "Prices"
  (pill-style tabs using the real app's pattern: active tab has gold color + subtle
  background; inactive tabs are muted)

**Details tab content:**
  - A definition list showing:
    - Color: Red
    - Type: Leader
    - Cost: 5
    - Power: 5000
    - Counter: —
    - Attribute: Strike
    - Archetype: Straw Hat Crew
  - Effect text block (dark surface card):
    "When this card attacks, give 1 of your Leader or Character cards +1000 Power for this battle."

**Variants tab content:**
  - Two variant cards in a horizontal scroll row:
    - Base: "OP01-001" · market price $35.20
    - Alt-Art: "OP01-001 AA" · market price $68.00
  - Each variant card has the same aspect-ratio 5/7 image placeholder as the main card,
    a label below, and the price in gold monospace

**Prices tab content:**
  - Two price rows (styled like the real app's price card):
    - Row 1: $35.20 · TCGPlayer · Market · Last updated May 5, 2026
    - Row 2: ¥4,800 · CardRush · In-stock · Last updated May 5, 2026
  - Source label, price in gold, update time in muted text
  - No "floor price", no "buy now", no urgency copy — just the numbers and source

### 3. Fixed bottom action bar (same pattern as real app)
- "♥ Watchlist" toggle button (left half)
- "Add to Deck" button (right half, disabled/muted)
- Both full-height with gold-themed active state on Watchlist
- Bar is sticky at bottom, dark semi-transparent background with blur

## Interactions required

- Tab switching: clicking Details / Variants / Prices shows that section, hides others.
  No animation needed — instant switch is fine.
- Watchlist toggle: same as L1 — toggles active/inactive state with CSS transition.
  Active state: gold background + "♥ Watching" text.
  Inactive state: outline + "♥ Watchlist" text.
- Back button: no actual navigation (this is a standalone page). Just aria-label it.
